# 🗺️ ErrandPlanner MVP

**Transform chaotic errands into efficient routes with one click.**

## 🎯 What We're Building

ErrandPlanner is a mobile-first web application that optimizes multiple errand locations into the most efficient driving route using Google Maps API integration. Users simply input their errand locations, and the app automatically calculates the best path to save time, gas, and reduce stress.

## 🚨 The Problem We're Solving

### **Current Pain Points:**
- **Time Wasted:** People spend 2-3 extra hours weekly driving inefficiently between errands
- **Money Lost:** Poor route planning increases gas costs by 20-40%
- **Decision Fatigue:** Constantly figuring out "what's the best order to visit these places?"
- **Stress & Frustration:** Running late because of inefficient planning

### **Real User Scenarios:**
- Parent with kids' activities at different locations across town
- Professional with multiple client visits in one day
- Weekend warrior trying to hit grocery store, pharmacy, bank, and post office
- Senior wanting to minimize driving complexity and time on road

## ✅ Our Solution

### **Core Features:**
- **Simple Input:** Add errand locations via text input
- **Smart Optimization:** Google Maps API calculates most efficient route
- **Mobile-First:** Responsive design for on-the-go planning
- **Instant Results:** Real-time route optimization and time estimates
- **Clean Interface:** Minimal, intuitive design anyone can use

### **Value Delivered:**
- ⏰ **Save 30-60 minutes** per errand trip
- ⛽ **Reduce gas costs** by optimizing routes
- 🧠 **Eliminate decision fatigue** with automated planning
- 📱 **Mobile accessibility** for real-time route adjustments

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **API:** Google Maps Directions API
- **Deployment:** Netlify
- **Repository:** GitHub

## 🚀 Getting Started

1. Clone the repository
2. Add your Google Maps API key to `app.js`
3. Open `index.html` in browser or deploy to Netlify
4. Start adding your errands and optimize your routes!
